# assets

Drop the original dark-city photograph here as `background.png` (or `background.jpg`).
`scene.js` loads it automatically and cover-fits it onto the backdrop plane, where the
LED panels, neon tubes and light rails illuminate it. When the file is absent the same
scene (concrete towers, lit windows, truss bridge with the train, red/cyan kanji neon)
is painted procedurally so the render still works.
